airo_ads

Google Mobile Ads SDK wrapper with Aika Frequency Policy Engine, dark-mode native ad cards, non-intrusive pause overlays, lower-third banners, and zero-dependency GAM VAST/VMAP XML tag parser for Flutter apps.

✨ AI Agent Prompt (skill.sh compatible) Standard Flutter Architecture Prompt
Run `npx skills use "https://github.com/flutter/agent-plugins" --skill "flutter-apply-architecture-best-practices"`

Key Package Capabilities

⏱️

Aika Frequency Engine

Enforces automated session warmup (5 minutes ad-free) and customizable impression cooldowns to protect user retention.

⏸️

In-Stream Pause Overlays

Renders sleek, high-res ad card overlays over video streams when paused, without interrupting audio playback or casting state.

📺

Non-Linear Lower-Third Ads

Translucent non-linear banner overlay sliding into the bottom 20% of the viewport during live sports or media streams.

📑

Zero-Dependency VAST Parser

Construct Google Ad Manager (GAM) VAST endpoints and parse VAST XML responses cleanly without bloated third-party dependencies.

🛡️

Zero-Crash Safe Stubs

Safe by default across Web, TV, Desktop, and Casting targets, failing silently with zero visual overflow artifacts.

🎨

Native Dark Mode Templates

Responsive small and medium card layouts with automatic dark/light theme color matching.

End-to-End Flutter Implementation
lib/main.dart 
import 'package:flutter/material.dart';
import 'package:airo_ads/airo_ads.dart';

void main() async {
  WidgetsFlutterBinding.ensureInitialized();
  
  // Initialize AikaAdManager at launch
  await AikaAdManager.instance.initialize();
  
  runApp(const MyApp());
}

class VideoPlayerScreen extends StatefulWidget {
  @override
  _VideoPlayerScreenState createState() => _VideoPlayerScreenState();
}

class _VideoPlayerScreenState extends State<VideoPlayerScreen> {
  bool _isPaused = false;

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      body: Stack(
        children: [
          VideoView(onPause: () => setState(() => _isPaused = true)),

          // In-Stream Pause Ad Overlay Wrapper
          AiroPauseAdOverlay(
            isPaused: _isPaused,
            adUnitId: 'ca-app-pub-3940256099942544/6300978111',
            child: Container(),
          ),
        ],
      ),
    );
  }
}
